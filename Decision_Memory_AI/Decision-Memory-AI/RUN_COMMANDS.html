Decision Memory AI — Run Commands & Quickstart Guide 🧠

All main entry commands to run, test, and expose Decision Memory AI.

⚡ Quick Start (2 Separate Terminals)

1. Backend Server Port 8000

cd backend
npm install
npm start

Development auto-reload mode: npm run dev

Health check: http://localhost:8000/health

2. Frontend Dashboard Port 5173

cd frontend
npm install
npm.cmd run dev

Dashboard URL: http://localhost:5173

💻 Run Directly from Project Root (Single Terminal)

# Start Backend
npm.cmd --prefix backend start

# Start Frontend
npm.cmd --prefix frontend run dev

🐳 Docker (All-in-One)

docker compose up -d --build
docker compose down

🧪 Testing & Verification Commands

Command Description
npm.cmd --prefix backend test End-to-end HTTP integration test (Health, MRs, Decisions, Semantic Search)
npm.cmd --prefix backend run test:apis Test live credentials for GitLab and Cohere AI
npm.cmd --prefix backend run test:local Test SQLite database operations & vector search
npm.cmd --prefix backend run recreate-db Drop & recreate all database tables cleanly
npm.cmd --prefix backend run mock Start mock presentation API server

🌐 Expose GitLab Webhooks (Ngrok)

ngrok http 8000

Add forwarding URL into GitLab: https://<your-id>.ngrok-free.app/webhook/gitlab
